# SwitchCase IaC Diagrams desktop downloads

Official binary distributions for SwitchCase Infrastructure (IaC Diagrams).

Use the [download and setup page](https://switchcasestudios.com/downloads/iac-diagrams.html) for Windows, macOS and Linux packages, requirements, SHA-256 checksums and verification limits. The separate Node.js CLI remains available there.

Desktop packages bundle the runtime. Windows and macOS builds are unsigned; macOS is not notarized. Linux is a preview with GUI interaction not verified. Intel Mac verification used Rosetta, not Intel hardware. Read the release notes before downloading and keep OS security protections enabled.

This repository holds distribution information and release binaries only. Application source is maintained separately. GitHub's automatic Source code ZIP/tar downloads are not the application or desktop installer; choose a named platform asset under Releases.
